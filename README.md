Java Programs

About the Project

Welcome to my Java Programs repository!

This repository contains a collection of Java programs developed to practise programming fundamentals, improve logical thinking, and understand basic Java concepts.

Programs Included

1. addition.java – Performs basic addition operations.
2. char_diamond.java – Prints a diamond pattern using characters.
3. gradeCalculation_method.java – Calculates student grades using Java methods.
4. numbers_pyramid.java – Prints a pyramid pattern using numbers.
5. Palindrome.java – Checks whether a given number is a palindrome.

Technologies Used

- Java
- Conditional Statements
- Loops
- Methods
- Basic Programming Concepts

How to Run

1. Clone the repository:

git clone https://github.com/lakshmikumarlk7257754-sudo/java-programs

2. Open the project folder in VS Code or any Java IDE.

3. Compile the Java file:

javac addition.java

4. Run the program:

java addition

Replace the file and class name with the program you want to execute.
